Garmin jetzt abrufen

„Garmin jetzt abrufen“ oeffnet GitHub -- dort einmal auf Run workflow tippen, etwa 2 Minuten warten, dann oben rechts auf Aktualisieren tippen. Der Knopf oben rechts holt nur den zuletzt veröffentlichten Stand nach, er startet selbst keinen neuen Abruf bei Garmin.

Quelle: dein Garmin-Konto, lokal synchronisiert. Schlaf, HRV und Atmung erscheinen nur für Nächte mit getragener Uhr. Die Bewertungen hier sind Faustregeln aus der Trainingslehre, kein medizinischer Rat.
